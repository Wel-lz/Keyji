## Проблема

Для раскладки, которая нужна *изредка* — японский у изучающего, кириллица у эмигранта, арабица раз в неделю, — Windows даёт два плохих варианта:

- **Держать установленной** — и она навсегда торчит в цикле `Win+Space`, и ты десятки раз в день перещёлкиваешь мимо неё к двум раскладкам, которыми реально пользуешься.
- **Удалить** — и каждый раз, когда она *понадобилась*, лезешь в Параметры → Язык → Добавить, ждёшь пакет, потом удаляешь обратно.

Ни то ни другое не подходит для языка, который нужен редко, но по-настоящему. Этот зазор и закрывает Keyji.

## Как это работает

Keyji живёт в системном трее. Клик открывает **панель Keyji** — компактный список, где ты включаешь или выключаешь редкую раскладку: появляется, когда нужна, исчезает, когда нет. Закрепи ту, к которой тянешься чаще всего, — и один клик переключает её прямо из трея, не засоряя повседневный цикл.

- **Один клик из трея** — мгновенно включить или выключить раскладку. Без Параметров, без перещёлкивания.
- **Статус в трее** — иконка показывает, что активно сейчас.
- **Понятный онбординг** — выбираешь языки при первом запуске: из курируемых пресетов или полного каталога Windows. Рассчитан на нетехничного пользователя.
- **Нативно и мгновенно** — работает с языковыми профилями Windows напрямую (WinAPI / TSF), без запуска `powershell.exe` на каждое действие. Переключение — заметно быстрее 100 мс.
- **Один файл, ничего не ставить** — скачал один self-contained `.exe`, двойной клик, готово. Ни инсталлятора, ни докачки рантайма.

## Для кого

- **Изучающие язык**, кому скрипт нужен для учёбы, а не для ежедневного набора.
- **Мультиязычные пользователи**, кто меняет скрипт изредка, а не постоянно.
- **Все**, кого достала редкая раскладка, забивающая цикл `Win+Space`.

## Чем Keyji **не** является

Это **не** замена `Win+Space`. Штатное переключение циклирует между *активными* раскладками; Keyji решает, *какие раскладки вообще в этом цикле* — вводит редкую по требованию и убирает обратно. Другая задача.

## Статус и roadmap

Keyji написан на **C# / .NET (WPF)**.

- **v0.1.0 (выпущено)** — панель-тогл из трея (основной UI), онбординг при первом запуске с курируемым списком пресетов и полным каталогом Windows, опциональный закреплённый язык для тогла в один клик, интерфейс на английском / русском / японском, светлая и тёмная темы вслед за Windows, автозапуск, нативное чтение/запись (WinAPI / TSF), один self-contained `.exe`.
- **Дальше** — глобальный хоткей, подписанный инсталлятор + `winget`, авто-обновление, больше курируемых пресетов, правила по приложениям *по запросу*.
- **Никогда** — кроссплатформенность, облачная синхронизация, замена `Win+Space`, превращение в комбайн настроек.
